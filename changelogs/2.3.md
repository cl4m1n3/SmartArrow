# 2.3.0
Released 16th September 2024.

**For PocketMine-MP 5.0+**
This is the support version for the latest PocketMine-MP kernels

## General
- Updated code structure.

## New
- The plugin API has been added
- Support for enabling/disabling all plugin commands

## Fixes
- Adjustments to the `getPreemtive()` function to calculate the lead correctly
- Adjustments in function `onArrow()` to handle all smart arrows
- Minor bugs in the code have been removed

## Config
- The ability to adjust the arrow flight speed has been temporarily removed due to problems in calculating the lead

## SmartArrow API
- Check out the [documentation](https://github.com/cl4m1n3/SmartArrow/blob/PMMP-5/documentation.md) for working with the plugin
